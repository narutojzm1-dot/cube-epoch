# UI-020 白天建造完整步骤入口

## 问题依据与选定范围

正常法师新局下移一格、面朝右砍(25,22)树并拾取木头；选火把点刚砍出的空地，优先消费初始成火把。保持建造选中时，320反馈区高60px、内容70px，“再点背包同一项取消”末段底部超过可视底边。**原生上滑原反馈区10px能读全，真实再点背包火也能取消；不是取消输入失效。**

实际困扰是首屏要猜隐藏滚动，而现有“怎么玩”打开的暂停帮助只给键盘“按0取消”，触屏段没有同项取消；无法在这个显式指导入口找到完整当前步骤。最小改进：白天触控选中建造时，原44px帮助按钮显示“建造说明”；帮助首屏按行列出现有build-banner的名称、原配方、放置/修墙与同项取消。全部由原显示文本按“ · ”分句，未另造配方/操作。取消后按钮恢复“怎么玩”，夜战和键鼠原入口保留。

**本片是可达完整说明改进，不是增高/取消原限高裁切。** 原60px反馈、原滚动、地图高度、字号/44px控制、背包信息保留；旧次说明仍限高可滚。320旧提示不是被新文案误称“已无裁切”。
